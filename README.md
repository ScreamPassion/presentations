# Гвендолин · ночные лекции

Коллекция HTML-презентаций «на почитать вечером»: плотный текст, конкретные цифры, картинки на каждую главу, один слайд - одна мысль. Всё собрано в одном стиле, открывается любым браузером, без сборки и зависимостей: `<папка>/index.html`, стрелки для листания, `map.html` - оглавление.

Сайт с оглавлением всех презентаций: [screampassion.github.io/presentations](https://screampassion.github.io/presentations/).

## Как это сделано

Тексты и структура - совместная работа автора и ИИ по пятницам: вопросы, споры, проверка фактов и вёрстка. Картинки - генерация нейросетью (Nano Banana Pro) в собственном проекте автора, диаграммы в «Изобретаем хаос» посчитаны кодом. Каждый слайд проверяется на 1600×900 headless-браузером, все факты - из открытых источников, спорные величины помечены как оценки.
